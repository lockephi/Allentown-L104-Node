DAEMON LIFECYCLE (Per Cycle)
────────────────────────────────────────────────────────────────────────────

    1. CYCLE START
       adapter.on_cycle_start()
           ↓
    2. ORCHESTRATOR SCHEDULES TASK (if resources available)
       Task pulled from priority queue
           ↓
    3. DAEMON RUNS WORK
       Run simulations, improve code, check consciousness, etc.
           ↓
    4. CYCLE END + METRICS
       adapter.on_cycle_end(success, duration_ms, cpu%, memory_mb)
           ↓
       Orchestrator updates:
       • Daemon health score
       • System metrics
       • Health status (HEALTHY/DEGRADED/CRITICAL)
           ↓
    5. EMIT EVENTS (optional)
       adapter.emit_fidelity_alert(fidelity, trending)
       adapter.emit_error(error_type, message)
       adapter.emit_success(task_type, summary)
           ↓
    6. EVENT BUS DELIVERS
       Subscribers instantly notified
       (no file polling!)

HEALTH MONITORING EXAMPLE
────────────────────────────────────────────────────────────────────────────

    Normal Load:
        Daemon Health: 0.95 ✓ | Resource Available: 0.90 ✓
        → Overall Health = (0.95 × 0.6) + (0.90 × 0.4) = 0.93
        → Status: HEALTHY
        → Action: Schedule full batch of 3 tasks

    Degraded Load:
        Daemon Health: 0.75 | Resource Available: 0.55
        → Overall Health = (0.75 × 0.6) + (0.55 × 0.4) = 0.67
        → Status: DEGRADED
        → Action: Schedule only top 1 task, extend intervals

    Critical Load:
        Daemon Health: 0.50 | Resource Available: 0.20
        → Overall Health = (0.50 × 0.6) + (0.20 × 0.4) = 0.38
        → Status: CRITICAL
        → Action: Pause scheduling, focus on recovery

INTEGRATION (Per Daemon) - 4 Simple Steps

    STEP 1: Import
    ─────────────
    from l104_daemon_adapter import DaemonAdapter

    STEP 2: Create Adapter
    ─────────────────────
    self.adapter = DaemonAdapter("vqpu_daemon", orchestrator)

    STEP 3: Wrap Cycle
    ─────────────────
    self.adapter.on_cycle_start()
    try:
        # ... existing cycle code ...
    finally:
        self.adapter.on_cycle_end(success, duration_ms, cpu_pct, mem_mb)

    STEP 4: Emit Metrics
    ───────────────────
    self.adapter.emit_fidelity_alert(fidelity, trending, sim_count, errors)

    Total: ~20 lines of code per daemon


DATA FLOW: Fidelity Alert

    VQPU Daemon

        ├─ Detects trending down
        │

                │
                ↓
        Event Bus (In-Memory Queue)
                │
                ├─ fidelity_update event
                ├─ Timestamp: now
                ├─ Payload: {fidelity: 0.95, trending: "down", ...}
                │
                └─→ Orchestrator distributes to subscribers
                    │
                    ├─→ [Subscriber 1] Logs alert
                    ├─→ [Subscriber 2] Bumps priority of next VQPU task
                    ├─→ [Subscriber 3] Triggers health re-assessment
                    └─→ [Subscriber 4] Updates dashboard

    All subscribers notified in <1ms (no file I/O!)
